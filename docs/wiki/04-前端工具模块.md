### 6.2 screen-recorder/（录屏 + GIF 编辑器）

**types.ts**：`CaptureTarget{mode:'region'|'window'|'monitor', monitorId?, windowId?, rect?}`、`RecordingSettings{fps:15|30|60, quality:'high'|'balanced'|'small', countdownSec, cursorHighlight, audio{microphone,system}}`、`RecordingArtifact{path,durationMs,fps,captureBackend,sizeBytes...}`、`GifFrame{id,delayMs,width,height,rgba,annotations}`、`RecorderAction`（17 种 action 联合）。

**useRecorder.ts**（Tauri IPC 封装）：
- `listen('recording-status')` 接收 `{sessionId, status, elapsedMs, fps, droppedFrames, artifact?}`；
- `refreshSources()` → `Promise.allSettled([list_capture_monitors, list_capture_windows, list_audio_sources])`；
- `start/pause/resume/stop/cancel` → 对应 invoke；
- `exportRecording(format, options, outputPath)` → `export_recording`（gif 预置 fps:12/maxWidth:800/loop:0）；
- `loadPreview()` → `convertFileSrc(artifact.path)`（**asset:// 直读**，避免 IPC 字节传输）；
- `prepareGifEditor()` → Rust 把 MP4 预转临时 GIF。

**recorder-reducer.ts**：`recorderReducer(state, action)` 纯 reducer 管理 idle→countdown→recording⇄paused→stopping→preview/error 状态机 + GIF 工程（load/selected/deleted/duplicated/reordered/delayChanged/loopChanged/annotationAdded（支持 applyToAll）/resized/cleared）。

**index.tsx**（ScreenRecorder）：`useReducer` + `useRecorder` 双层；250ms 轮询计时；区域框选 `start_recording_region_selection` + `listen('recording-region-selected'/'-cancelled')`；`startRecording()` 构造 target → 倒计时 → `recorder.start`（期间已 stopped 则放弃）；预览 `<video>` 播放 artifact、导出 MP4/GIF、**编辑 GIF**（`prepareGifEditor` → fetch → `decodeGif` → `gifLoaded` → GifEditor）。

**gif-worker.ts**（主线程 + Worker 双角色模块）：
- `decodeGif(arrayBuffer)`：**gifuct-js** parseGIF+decompressFrames，`applyPatch` 处理 disposalType 2/3，产出逐帧完整 RGBA；
- `encodeGif(frames, loopCount, maxWidth=800)`：`renderAnnotations`（离屏 canvas 画 rect/arrow/text/mosaic 标注）→ **gifenc** quantize/applyPalette/writeFrame；
- Worker 协议：`{type:'decode'|'encode', id, buffer?/frames?}`。

**GifEditor.tsx**：select/rect/arrow/text/mosaic 工具、双击加标注（可 applyToAll）、按帧 delay 的 setTimeout 链播放、resize/crop 逐帧重采样、导出。`Timeline.tsx` 帧条（删除/复制/拖拽排序/改 delay）。

## 7. network/

### 7.1 api-tester/（HTTP API 调试，重点）

主组件 `ApiTester`（[index.tsx](../../src/tools/network/api-tester/index.tsx)）—— **`handleSend()` 请求管线**：

```mermaid
flowchart LR
    A[buildUrl 拼 query] --> B[resolveVariables 变量替换<br/>全局变量 + 激活环境覆盖]
    B --> C[Auth 注入<br/>bearer / basic(btoa) / apikey(header或query)]
    C --> D[Body 构造<br/>form-data→urlencoded / Content-Type]
    D --> E[前置脚本 executeScript<br/>Worker 沙箱可改写 request]
    E --> F{Mock 拦截?}
    F -- 命中 MockRule --> G[generateMockResponse<br/>延迟模拟 + x-mock:true]
    F -- 未命中 --> H[sendRequest<br/>plugin-http(Tauri)/fetch(浏览器)]
    G --> I[后置脚本 executeScript]
    H --> I
    I --> J[setResponse / setScriptLogs / addHistory]
```

## 11. 特殊窗口应用与两个高含金量算法

### screenshot/（微信风格截图独立窗口）

- **ScreenshotApp.tsx**：启动即隐藏预热；`listen('screenshot-capture-ready', {generation})` → `get_screen_capture` 拿截图文件路径 → `convertFileSrc` + `crossOrigin='anonymous'` 加载（**asset.localhost 跨源，不设 anonymous 会污染 canvas**）→ `show_screenshot_window(generation)`（失败重试 3 次）；
- **ScreenshotOverlay.tsx**：三模式复用（normal/longshot/recording）；状态机 idle→drawing→selecting→selected；矩形/手绘双选区；8 种标注工具；**数组快照式撤销**；马赛克（DOM canvas 不在 Konva 场景，导出时手动合成到 `stage.toCanvas()` 结果）；F 键整屏直出；关闭前先 `stopMouseTracking()`（**同步断开鼠标监听防迟到的 mouseup 复活会话**）；
- **longshot/LongshotPanel.tsx**：循环 `capture_screen_region` 采集 → 自动滚动 `send_scroll_wheel` → `listen('longshot-esc')` 退出。

### 长截图拼接算法（[lib/longshot-stitch.ts](../../src/lib/longshot-stitch.ts)）

- 灰度降采样（320 对齐 / 160 精拼）+ 帧间垂直重叠搜索 `findVerticalOffset(prev, next, hint?)`；
- **稳健统计门控**：逐行 SAD，`ROW_INLIER_TAU=12` 判 inlier 行，要求 inlier 比例 ≥0.9 且平均 SAD≤6.0 才算对齐成功 —— 专为代码类重复纹理防误配（"宁丢帧不重复"）；
- `framesIdentical`（SAD<0.75 判未滚动，丢弃）；DyHint 时间连续性先验（历史 dy 中位数 ±20% 收窄搜索窗）；重叠窗 [5% 帧高, 帧高-1]。

### sticky-note/（便签独立窗口）

文档模型 `StickyNotesDocument{notes[], activeId, alwaysOnTop}`，持久化经 Rust（`get_sticky_notes/update_sticky_notes`）；多便签 Tab（随机 5 色）、普通/时间线双模式、标题重命名、搜索、拖拽排序（140ms 激活延迟区分点击/拖动）、右键菜单；`useApplyTheme` 同步主应用主题。
