# React Flow 图表编辑器方案

## 定位

新增结构化图表编辑器，服务于流程图、架构图、数据流图和简单 UML。它与 Tldraw、Excalidraw 的自由白板能力并存，不替换已有工具。

## 首版范围

- React Flow 无限画布：拖拽、缩放、平移、框选、网格和缩略图。
- 矩形、圆角矩形、圆形、菱形、文本五类节点。
- 创建带箭头的连线，支持删除、复制和属性编辑。
- 节点注册表，为业务节点和社区扩展保留稳定入口。
- 带 `schemaVersion` 的 JSON 导入导出。
- SVG 导出和 SVG 栅格化 PNG 导出。
- 撤销、重做、新建、打开、保存和浏览器下载回退。

## 文档模型

文档包含 `schemaVersion`、`nodes`、`edges` 和 `viewport`。导入未知节点时回退为通用节点并保留原始类型，避免文件无法打开。

## 后续阶段

对齐与分布、组合和容器节点、Dagre/ELK 自动布局、正交连线、障碍物避让、纯 SVG 节点渲染器、模板库和构建时扩展包。
