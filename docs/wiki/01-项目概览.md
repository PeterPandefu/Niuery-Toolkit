# 01 · 项目概览

## 1. 项目定位

Niuery Toolkit 是一款**离线优先（Offline-first）的开发者工具箱**，DevToys 的同类克隆。绝大多数工具在本地运行；仅翻译（百度翻译 API）、HTTP API 调试、WebSocket 调试等工具在明确使用时访问网络。

- **产品名**：Niuery Toolkit（`com.niuery.toolkit`）
- **版本**：1.2.1（`package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml` 三处同步）
- **形态**：Windows 桌面应用（NSIS 安装包，`currentUser` 安装模式），带系统托盘与自动更新（Tauri updater）
- **许可**：MIT

## 2. 功能清单（50 工具 / 10 分类）

| 分类（category id） | 数量 | 工具 |
| --- | --- | --- |
| 数据与转换（data/converter） | 12 | JSON↔YAML、XML↔JSON、时间戳转换、进制转换、颜色与取色（6 子页签）、数据单位换算、角度转换、坐标归属查询、JSON 格式化、XML 格式化、SQL 格式化、数据报告生成器 |
| 编码与安全（security/encoder） | 9 | Base64、URL 编解码、HTML 实体、Unicode 转义、JWT 解析器、GZip 压缩、哈希计算、密码生成器、文件校验和 |
| 文本与代码（text） | 10 | Markdown 编辑器、文本对比、正则测试、大小写转换、文本分析、转义处理、HTML 离线渲染器、Mermaid 实时编辑器、PlantUML 实时编辑器、悬浮便签 |
| 生成工具（generator） | 4+3 | 二维码生成与识别、UUID 与随机 ID、Lorem Ipsum、应用图标生成（另含哈希/密码/校验和归入生成器目录） |
| 图像与文档（image/graphic） | 3 | 图片工作室（14 功能面板）、SVG 优化、PDF 处理（6 功能） |
| 图表与画布（canvas/diagram） | 3 | 思维导图、Excalidraw 白板、Tldraw 白板 |
| 截图与录制（capture） | 2 | 截图与标注（微信式截图 + 长截图）、屏幕录制（区域/窗口/显示器 + GIF 编辑） |
| 接口与网络（network） | 2 | HTTP API 调试（集合/环境/Mock/脚本）、WebSocket 调试（客户端 + 服务端） |
| 系统工具（system） | 4 | 系统监控、剪贴板历史记录、端口进程终止、文件占用解除 |
| 语言翻译（language/translate） | 1 | 多语言翻译（百度翻译） |

> 注：注册表 `category` 字段使用 10 个分类 id（`data / security / text / generator / image / canvas / capture / network / system / language`），源码目录按 `converter / encoder / formatter / generator / graphic / diagram / network / pdf / system / text / translate` 组织，两者为映射关系而非一一对应。

## 3. 技术栈

| 层级 | 技术 |
| --- | --- |
| 前端框架 | React 19（StrictMode）+ TypeScript 5.8 |
| 构建工具 | Vite 6（多 HTML 入口：index.html + sticky-note.html） |
| 样式 | Tailwind CSS 3.4 + CSS 变量主题（46 令牌 × 6 皮肤 × 明暗） |
| 状态管理 | Zustand 5（persist / sessionStorage / 内存 Map 三种形态） |
| 代码编辑器 | Monaco Editor（本地化 loader，12 个自定义主题） |
| 国际化 | i18next + react-i18next（中/英，localStorage 键 `niuery-toolkit-lang`） |
| 画布引擎 | Konva + react-konva（截图标注 / GIF 编辑器） |
| 图表渲染 | Mermaid 11（+ZenUML 外部图）、PlantUML（Rust + Java 管道渲染） |
| 白板 | Excalidraw 0.18 / Tldraw 5（本地资产） |
| 思维导图 | simple-mind-map 0.14（Export/Search/KeyboardNavigation 插件） |
| 搜索 | Fuse.js 模糊搜索 + pinyin-pro 拼音/首字母检索 |
| 桌面框架 | Tauri v2（Rust，edition 2021） |
| Rust 关键库 | xcap（捕获）、image、arboard（剪贴板）、sysinfo（监控）、tokio-tungstenite（WS 服务）、rfd（对话框）、zip、sha2、windows 0.58（DWM/GDI/IP Helper/Restart Manager 等 FFI） |
| 单元测试 | Vitest 4 + Testing Library（jsdom） |
| E2E 测试 | Playwright（驱动浏览器模式前端） |
| 代码规范 | ESLint 9 扁平配置 + Husky + lint-staged（pre-commit：tsc -b + eslint --fix） |
