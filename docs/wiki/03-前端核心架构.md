# 03 · 前端核心架构

> 覆盖：入口分派、App 装配、工具注册表、8 个 Store、布局组件、共享组件、Hooks、日志系统、平台能力探测。

## 1. 入口分派（[src/main.tsx](../../src/main.tsx)）

`main.tsx` 承担"窗口路由"职责，依据 `window.location.hash` / `pathname` 选择根组件：

| 判定条件 | 渲染组件 | 用途 |
| --- | --- | --- |
| `#/screenshot*` | `ScreenshotApp` | 截图捕获覆盖窗（透明） |
| `#/longshot-panel?x&y&w&h&i&a` | `LongshotPanel` | 长截图悬浮控制面板（query 携带区域参数） |
| `#/recording-cursor-highlight` | `CursorHighlightOverlay` | 录制光标高亮窗 |
| `#/recording-capture-border` | `RecordingCaptureBorderOverlay` | 录制边框窗 |
| pathname 以 `/sticky-note.html` 结尾 | `StickyNoteApp` | 便签独立窗口 |
| 其余 | `App` | 主窗口 |

启动序列：导入字体 → `index.css` → `i18n`（副作用）→ `store/log-store`（副作用，接通日志管道）→ `markPerformance('app:main-start')` → hash 分派（透明窗口强制 `documentElement/body` 透明 + `overflow:hidden`）→ 注册全局 error/unhandledrejection → `createRoot` 渲染（StrictMode）。

> React Router（react-router-dom@7）虽在依赖与 vendor chunk 中，但源码未实际使用 —— **工具导航由 Zustand 状态驱动**。

## 2. 主窗口装配（[src/App.tsx](../../src/App.tsx)）

```
App
├─ useApplyTheme()                          // 主题写入 DOM + 原生窗口 chrome
├─ 订阅 activeToolId / initAlwaysOnTools
├─ effect: 监听 window 事件 'open-resource-manager'
├─ effect: Tauri 下 listen 三个后端事件
│    open-screen-recorder → openTool('screen-recorder')
│    open-longshot-editor → openTool('screenshot-editor')
│    open-screenshot-ocr {imageDataUrl,text,translate?}
│        → translate? openTranslatorWithText(text) + setScreenshotSession
│        → 否则 setScreenshotSession + openTool('screenshot-editor')
└─ JSX:
   <div class="app-chrome app-shell h-dvh flex-col">
     <AtmosphereLayer pointerGlow />        // 指针光晕/流苏 canvas
     <Sidebar onSelectTool={openTool} />
     <ToolPanel toolId onOpenSettings />    // 工作台（含日志抽屉）
     <StatusBar />
     <SearchDialog onSelectTool={openTool} />
     <SettingsDialog open initialTab onClose />
     <Toaster position="bottom-right" />   // sonner
     <NativeFileDropBridge />              // 全局拖放桥（无 UI）
   </div>
```

## 3. 工具注册表（[src/registry/tool-registry.ts](../../src/registry/tool-registry.ts)）

### 3.1 核心类型（[src/types/tool.ts](../../src/types/tool.ts)）

```ts
interface ToolDefinition {
  id: string;            // 唯一标识（i18n key: tools.<id>、日志 source）
  name: string;          // 默认显示名（i18n 缺失兜底）
  icon: ComponentType<{className?}>;
  category: ToolCategory; // 10 类之一
  component: LazyExoticComponent<ComponentType>;  // React.lazy 代码分割
  preload?: () => Promise<unknown>;                // 悬停预加载（与 component 共用 dynamic import）
  keywords: string[];    // 搜索关键词（中英文）
  description: string;
  capabilities: ToolCapabilities; // 能力声明（自动推导或显式给出）
}
```

配套类型：`ToolCategory`（10 类有序）、`TOOL_CATEGORY_ORDER`、`CATEGORY_NAMES/CATEGORY_ICONS`、`ToolNetworkMode('offline'|'network'|'hybrid')`、`ToolCapabilityId('file'|'clipboard'|'screen'|'microphone'|'systemAudio'|'nativeWindow'|'system'|'localNetwork')`、`ThemeMode`、`SkinId`、`PointerEffect` 等。

### 3.2 注册表 API（模块级单例，非 store）

| 函数 | 说明 |
| --- | --- |
| `registerTool(tool)` | 写入 Map；capabilities 缺省时经 `resolveCapabilities()` 推导（显式表 `TOOL_CAPABILITIES` → category∈{network,language} 为 network → 其余 offline） |
| `getAllTools()` / `getToolsByCategory(cat)` / `getToolById(id)` | 查询 |
| `preloadTool(id)` | 首次触发预取（`preloadPromises` 去重，失败可重试）；触发时机：侧栏 hover/focus、搜索面板选中项变更 |
| `getAvailableCategories()` | 有工具的分类按固定顺序输出 |

文件底部以 **50 次静态 `registerTool({...})`** 集中注册全部工具；其中 `markdown-editor`、`html-renderer`、`mermaid-editor`、`plantuml-editor`、`excalidraw-board`、`tldraw-board`、`pdf-toolkit` 七个重型工具定义了 `preload`。

## 4. Store 层（Zustand 5，[src/store/](../../src/store/)）

### 4.1 app-store（全局应用状态，persist 键 `niuery-toolkit-store` v7）

| 字段 | 类型/默认 | 方法 |
| --- | --- | --- |
| theme / skin / atmosphere / pointerEffect / mascotEnabled | ThemeMode='system' / SkinId='forge' / 'off' / 'off' / false | `setTheme/setSkin/setAtmosphere/setPointerEffect/setMascotEnabled/resetAppearance` |
| activeCategory | ToolCategory\|null | `setActiveCategory`（侧栏手风琴） |
| activeToolId | string\|null（**非持久化**） | `setActiveTool` |
| recentToolUsage | `Record<string,{count,lastUsedOrder}>`（**非持久化**） | `recordToolUsage(id)`（全局递增序）、`getRecentToolIds(limit)` |
| searchOpen | false | `setSearchOpen` |
| pinnedTools | string[]（默认 7 项） | `setPinnedTools/togglePinnedTool` |
| sidebarCollapsed | false | `setSidebarCollapsed/toggleSidebarCollapsed` |

持久化 `partialize` 仅保留外观五项 + pinnedTools + sidebarCollapsed；自定义 `merge` 逐字段校验归一（`isSkinId` 等）防脏数据；`migrate` 版本升级兜底。

### 4.2 tool-lifecycle-store（工具进程式生命周期，persist 键 `niuery-toolkit-lifecycle`）

| 成员 | 说明 |
| --- | --- |
| `activeTools: string[]` | 当前挂载（运行中）工具 |
| `alwaysOnTools: string[]` | 常驻列表，默认 `['screenshot-editor','clipboard-history']` |
| `startTool(id)` | 幂等加入 activeTools |
| `stopTool(id)` | 常驻工具拒绝停止 |
| `toggleTool(id)` | 常驻不可关；运行中→stop，否则→start |
| `setAlwaysOn(id, bool)` | true 时同时确保启动 |
| `initAlwaysOnTools()` | activeTools ∪ alwaysOnTools（App 挂载与 rehydrate 时调用） |

只持久化 `alwaysOnTools`。

### 4.3 tool-state-store（每工具编辑状态，内存 Map，不持久化）

`states: Map<string, {input, output, options}>`；`getToolState / setToolState(浅合并) / clearToolState`；便捷 hook `useToolState(toolId)` 返回 `{state, setState, getInput, setInput}`。与 ToolPanel 的 keep-alive 渲染配合，实现工具切换状态保留。

### 4.4 log-store（日志状态，与 logger.ts 构成管道）

- `entries: LogEntry[]`（上限 `MAX_LOG_ENTRIES=2000` 环形裁剪）、`panelOpen`、`unreadCount`；
- `addLog(entry)`：与最后一条 source+level+message 相同则合并 `count+1`；面板关闭时累计 unreadCount；
- **管道接线**：`logger.ts` 持有可替换 sink（默认 console），`log-store.ts` 模块底部调用 `setLogSink(entry => useLogStore.getState().addLog(entry))` —— 解循环依赖；`main.tsx` 仅 `import './store/log-store'` 完成接线；
- `exportLogsAsText(entries)` 纯文本序列化（LogPanel 导出用）。

### 4.5 resource-store（资源管理状态）

状态：`resources: ResourceStatus[]`、`loading/error/progress: Record<ResourceId, ResourceProgress>`、`busy/errors`。
方法：`refresh()`（`refreshPending` Promise 去重；Tauri 下 `invoke('list_resources')`）、`run(id, command, args?)`（busy 防重入；command ∈ install/import/select_local/remove）、`setProgress`。
配套 hook `useResourceEvents()`：监听 `resource-progress` / `resource-operation-ended` / `resources-changed`。

### 4.6 api-tester-store（HTTP 调试，persist 键 `niuery-api-tester`）

同时是 api-tester 的**类型层**：`ApiRequest{method(7种)/url/params/headers/body(6种类型)/auth(4种)/preScript/postScript}`、`Collection{items: CollectionItem(request|folder 递归)}`、`Environment`、`HistoryEntry`（上限 100）、`MockRule{method/urlPattern/statusCode/headers/body/delay}`、`ScriptLog`；工厂函数 `createKeyValue/createRequest/createCollection/createEnvironment/createMockRule`（nanoid）。

关键方法：
- `resolveVariables(text)`：`{{key}}` 替换，全局变量为基础、激活环境变量覆盖，未命中保留原文；
- `setVariable(key,value)`：有激活环境写环境，否则写全局。

持久化：collections/environments/activeEnvId/globalVariables/history/mockRules/mockEnabled（**不含当前请求与响应**）。

### 4.7 screenshot-ocr-store（截图 OCR 会话，刻意不持久化）

`screenshotSession: {id, imageDataUrl, text} | null`、`pendingTranslation: {id, text} | null`；`setScreenshotSession / setPendingTranslation / consumePendingTranslation(id)`（id 匹配才消费，防竞态）。数据流：截图窗 OCR/翻译 → App.tsx 事件处理器写入 → screenshot-editor 的 ScreenshotOcrPanel / translator 工具消费。

### 4.8 translate-store（翻译凭据，persist 键 `niuery-translate-store`）

`baiduAppId / baiduSecret` + `setBaiduCredentials / resetTranslateData`。

## 5. 布局组件（[src/components/layout/](../../src/components/layout/)）

### 5.1 ToolPanel — 工作台核心（保活式多实例渲染）

**全应用最关键的渲染机制**：main 区渲染**所有运行中工具**，非当前的用 `hidden` 隐藏：

```tsx
activeTools.map(id => (
  <div key={id} className={id === toolId ? 'flex h-full animate-tool-enter' : 'hidden'}>
    {id === toolId && <ResourceNotice ids={TOOL_RESOURCES[id] ?? []} />}
    <LocalizedToolErrorBoundary toolId toolName>
      <Suspense fallback={<ToolLoader/>}>
        <ToolLoadTelemetry toolId/>
        <definition.component/>
      </Suspense>
    </LocalizedToolErrorBoundary>
  </div>
))
```

内部组件：
- `ToolLoader`：懒加载 fallback（Loader2 旋转）；
- `ToolLoadTelemetry`：`markPerformance('tool:<id>:selected')` → `measurePerformance('工具首次挂载')`；
- `WelcomeScreen`：欢迎语 + 大搜索框 + 固定工具网格 + 最近使用网格（`getRecentToolIds(usage, 6)`）+ 吉祥物侧栏；
- `ToolStoppedScreen`：工具停止后的重启动卡片；
- `ToolPowerSwitch`：电源开关胶囊（常驻禁用+Pin 样式；停止后 activeTool 切到剩余列表最后一个）；
- header 动作条：固定快捷栏（≤6 图标）→ 语言切换 → 主题三态循环 → 设置 → WindowControls。

### 5.2 Sidebar — 侧栏导航

- 数据：app-store + lifecycle-store + `getAvailableCategories()`；
- 折叠：BrandMark 点击 `toggleSidebarCollapsed`，CSS 16.5rem↔3.5rem（280ms 过渡）；折叠态分类点击弹 flyout 浮层（外点 pointerdown / Esc 关闭）；
- `ToolItem`：3px 激活指示条；状态角标优先级 常驻(Pin) > 运行中(绿点)；`onPointerEnter/onFocus` 触发 `preloadTool(id)`；
- 名称解析 `t(`tools.${id}`, tool.name)`；标题区含 `data-tauri-drag-region` 拖拽移窗。

### 5.3 SearchDialog — Ctrl+K 全局搜索

- 触发：全局 keydown `Ctrl/Cmd+K` 切换、Esc 关闭；打开保存焦点，关闭归还；
- **两级搜索算法**：
  1. 直接匹配：`buildToolSearchText()`（`lib/pinyin-search.ts`）把 id/名称/描述/keywords/分类拼接并追加**全拼+首字母拼音 blob**（pinyin-pro），支持拼音/首字母搜中文工具名（多 token AND 匹配）；
  2. 为空回退 Fuse.js 模糊搜索（keys 权重：localizedName 2.5 / searchText 2 / keywords 1.5 / description 1，threshold 0.4）；
- 无查询时分三段（固定/最近使用 ≤6/全部）；有查询单段结果 + 分类过滤 chip；
- 键盘 ↑↓/Enter、`scrollIntoView`、选中项变更即 `preloadTool`；完整 ARIA（dialog/combobox/listbox）。

### 5.4 SettingsDialog — 设置中心（6 页签）

- **appearance**：主题三选 → 皮肤网格（`getThemeTokens` 内联渲染迷你色卡）→ 氛围/吉祥物/指针特效开关 → 恢复默认；
- **alwaysOn / pinned**：分类分组 + 名称/keywords 筛选，逐行 Toggle 调 `setAlwaysOn` / `togglePinnedTool`；
- **hotkeys**：5 个动作（showWindow/stickyNote/screenshot/longshot/screenRecorder）；`invoke('get_hotkeys')` 拉取；`HotkeyRecorder` 录制组件（修饰键+主键捕获、Esc 取消）；提交 `invoke('update_hotkey')` 后 `emitHotkeysChanged`（window 事件 `niuery:hotkeys-changed`，已挂载工具热更新）；重置 `invoke('reset_hotkeys')`；
- **resources**：内嵌 ResourceManager；
- **updates**：`checkForAppUpdate` / `installAppUpdate`（plugin-updater + plugin-process relaunch）。

## 8. 日志系统（[src/lib/logger.ts](../../src/lib/logger.ts)）

```
任意模块 createLogger(source) → Logger{debug,info,warn,error,child}
    ↓ 级别过滤 + 400ms 同源同消息节流（details 序列化截断 800 字符）
setLogSink(sink)  ←—— log-store 模块底部注入 addLog
    ↓
useLogStore.entries（上限 2000，同消息合并 count）
    ↓
LogPanel 展示 / 复制 / 导出 txt + StatusBar unread 徽标
```

导出：`LogLevel`、`LogEntry{id,timestamp,level,source,message,details?,count}`、`createLogger(source)`、`appLogger`、`setLogSink`、`setMinLogLevel`、`serializeDetails`。`child(suffix)` 派生 `source:suffix` 实例。
