# 07 · 主题皮肤与国际化

## 1. 主题系统四层结构

### 1.1 令牌定义层（[src/lib/theme.ts](../../src/lib/theme.ts)）

- `ThemeTokens` 接口：**46 个 HSL 三元组字符串令牌** —— 基础 24 个 shadcn 系（background/foreground/card/popover/primary/secondary/muted/accent/destructive/success/warning/info/border/input/ring/radius/sidebar 系）+ 扩展（surface-raised、surface-overlay、**ember-glow** 余烬辉光、shadow-tint）+ **8 个语法高亮令牌**（syntax-keyword/string/number/title/type/variable/regexp/meta）；
- `SKINS: Record<SkinId, {id, light, dark}>`：**6 套皮肤 × 明暗 = 12 组完整令牌表**：

| SkinId | 中文名 | 风格 |
| --- | --- | --- |
| `forge`（默认） | 锻造 | 暖白纸面 + 锻铜强调，单一强调色全局锁定 |
| `ocean` | 海洋 | 海蓝系，泡泡上升粒子 |
| `forest` | 森林 | 林绿系，叶片下落粒子 |
| `mono` | 素墨 | 纯灰，**关闭一切特效**（无点阵/辉光/氛围/指针特效） |
| `aurora` | 极光 | 青紫双色漂浮呼吸粒子 |
| `ink` | 宣纸 | 墨朱，最少粒子（14 个） |

- 工具函数：`getThemeTokens(skin, scheme)`（缺省回退 forge）、`applyThemeTokens(root, tokens)`（逐令牌 setProperty）、`toHex/hslToRgb/getContrastRatio`（对比度校验与原生 API）、`isSkinId`、`SKIN_IDS`、`DEFAULT_SKIN='forge'`。

### 1.2 CSS 默认层（[src/index.css](../../src/index.css)）

`:root` 与 `.dark` 内置 forge 皮肤默认 CSS 变量（Tailwind `hsl(var(--x))` 消费）——**运行时会被 useApplyTheme 的内联 style 覆盖**，CSS 值仅为无 JS 兜底。`html[data-skin="mono"]` 与 `html[data-atmosphere="on"]` 选择器驱动氛围透明度与 mono 去特效。

自研设计类（`@layer utilities`）：`.app-chrome/.app-panel`（isolation: isolate 建立层叠上下文）、`.app-workbench`（22px 点阵纹理）、`.app-sidebar`（顶部渐变+软接缝）、`.app-sidebar-panel`（16.5rem↔3.5rem 过渡）、`.brand-mark`、`.panel-raised`、`.ember-glow`、`.kbd`（键帽）、`.tool-card`（hover 位移，mono/ink 禁用）、`.nav-item`、`.skip-link`（无障碍）。

### 1.3 应用层（app-store → useApplyTheme → DOM）

```
SettingsDialog 外观页 → app-store.setSkin/setTheme
    → useApplyTheme()（仅 App 根调用）
        → root.dataset.skin/atmosphere + .dark class 切换
        → applyThemeTokens(root, tokens)（逐令牌写 CSS 变量）
        → Tauri: invoke('set_window_chrome', {background, foreground, dark}) 同步原生标题栏
    → 全 UI（Tailwind 类）+ AtmosphereLayer + Monaco 即时换肤
```

### 1.4 编辑器层

`getMonacoThemeName(skin, scheme)` = `` `niuery-${skin}-${scheme}` ``；[monaco-setup.ts](../../src/lib/monaco-setup.ts) 中 `registerMonacoThemes(monaco)` 注册 12 个 Monaco 主题（base vs/vs-dark + editor 配色 + syntax-* 规则）。

## 2. 指针特效与氛围（[SkinAtmosphere.tsx](../../src/components/layout/SkinAtmosphere.tsx)）

`AtmosphereLayer({density='full', pointerGlow=false})` 两种形态：

1. **根层**（App 内，`fixed inset-0 z-[30]`）：指针特效 —— `glow`（半径 120、alpha 0.08 的 `--ember-glow` 径向渐变）或 `tassel`（[pointer-effect.ts](../../src/lib/pointer-effect.ts) 的 `createMagicTassel/stepMagicTassel/drawMagicTassel` 流苏粒子，`MagicSpark{kind: ember|drop|leaf|mote|seal, hue, generation, branched}`，慢速 30px 快速 14px 自适应间距）；`pointerEffect==='off'` 或 mono 皮肤直接 return null；
2. **区域层**（Sidebar/ToolPanel 内，`absolute inset-0 -z-[1]`）：氛围粒子（[atmosphere.ts](../../src/lib/atmosphere.ts)，`AtmosphereParticle` + 按皮肤差异化物理参数；ink 14 个、其余 42、mono 0）。

实现要点：rAF 主循环、devicePixelRatio（≤2）与 ResizeObserver、指针坐标同步排除 `.monaco-editor / canvas:not(.atmosphere-layer) / [data-atmosphere-exclude]`、`prefers-reduced-motion` 停动画保留静态粒子、`document.hidden` 停步进。

## 3. 国际化（[src/i18n/index.ts](../../src/i18n/index.ts)）

- 技术栈：i18next + react-i18next + i18next-browser-languagedetector；
- 资源：`locales/zh.json` / `en.json` **构建期静态打包**（无懒加载）；命名空间 `translation`；
- 初始化：`fallbackLng: 'zh'`；检测顺序 `['localStorage', 'navigator']`，缓存键 **`niuery-toolkit-lang`**；`interpolation.escapeValue: false`（React 已防 XSS）。

**Key 约定**：

| 前缀 | 内容 |
| --- | --- |
| `app.*` | 界面文案（搜索提示/离线模式等） |
| `categories.<category>` | 10 个分类名 |
| `tools.<toolId>` | 50 个工具名（SearchDialog 静态 import 用作拼音搜索语料） |
| `theme.*` | 主题/皮肤名+描述+指针特效 |
| `hotkeys.*` | 5 个快捷键动作 |
| `resources.*` / `updates.*` / `actions.*` | 资源管理/更新/操作按钮 |
| `capabilities.*` | 网络模式/权限/缺失提示 |
| `mascot*` | 吉祥物台词与小游戏 |

消费模式：`t('tools.<id>', tool.name)` 带兜底；ToolPanel 语言按钮 `i18n.changeLanguage` 即时切换（zh↔en）。

## 4. 吉祥物（[src/components/mascot/](../../src/components/mascot/)）

- `Mascot.tsx`：可交互桌面吉祥物（默认关闭）。状态机 `Pose: idle|float|pet|hop|perk|wink|nod` × `Motion: rest|fall|float|pop|drift`；拖拽放置（mascot-bounds.ts 边界跟随）、眨眼与瞳孔追踪、气泡台词（mascot-lines.ts）、reduced-motion 适配；
- `MascotCorner.tsx / MascotRace.tsx`：角落常驻小牛 + "冲栏"小游戏。
