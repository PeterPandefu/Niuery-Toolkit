## 快速上手（开发者视角）

```bash
npm install          # 安装依赖
npm run tauri:dev    # 桌面应用开发（完整功能，需 Rust 工具链）
npm run dev          # 仅浏览器模式（部分桌面功能不可用）
npm run test         # 前端单元测试（Vitest）
npm run test:scripts # 构建/发布脚本测试（node:test）
npm run test:e2e     # Playwright E2E（浏览器模式驱动前端）
cargo test           # Rust 单元测试（在 src-tauri/ 下执行）
npm run tauri:build  # 打包 NSIS 安装包
```

## 核心概念速览

- **工具注册制**：50 个工具通过 [tool-registry.ts](../../src/registry/tool-registry.ts) 声明式注册，自动接入搜索、快捷栏、生命周期管理。
- **工具生命周期**：仿 uTools 插件模型，工具按需启动/停止，支持「常驻」，切换不卸载组件（keep-alive 保活）。
- **前后端分工**：React 负责全部 UI 与纯计算；Rust 提供捕获/录屏/剪贴板/系统监控/快捷键/文件对话框/外部进程调用。
- **资源按需化**：Chromium、FFmpeg、Java/PlantUML、OCR 引擎不随安装包分发，首次使用时提示下载，全程 SHA-256 校验。
- **捕获并发安全**：截图/长截图/录屏三类捕获会话由 `CaptureGuard` 串行化，杜绝并发冲突。
